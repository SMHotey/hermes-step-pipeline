# Changelog

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — semver.
Ломающее изменение поведения движка или формата `pipeline.json` — минимум минор.

## [0.1.0] — 2026-11-01

Первая рабочая версия: конвейер шагов как плагин Hermes.

### Добавлено

- CLI `hermes pipeline setup|status|run|ui|doctor|notify-test|config`.
- Движок конвейера в `<проект>/.pipeline/`: реестр планов по файлам, контракт шага из
  плана, страж «шаг → постановка → исполнение → ревью → журнал → следующий шаг»,
  идемпотентные карточки канбана, инцидентные и владельческие стоп-флаги, ручной допуск.
- Роли-скиллы: orchestrator, prompter, reviewer, next-step, plan-authoring,
  agent-prompt-authoring.
- Локальный UI (stdlib, без сборки): поток шага, планы, шаги, карточки, журнал,
  кнопки тик/стоп/продолжить, настройки, самопроверка Telegram.
- Фоновый запуск UI: `--detach` (PID в `.pipeline/ui.json`), `--stop`.
- Предпросмотр без установки: `--preview` читает настоящие планы и карточки проекта
  движком плагина, ничего не записывая; действия выключены.
- Мастер установки спрашивает токен бота (скрытый ввод, проверка `getMe`), находит
  chat id через `getUpdates`, шлёт тестовое сообщение; уведомления через Bot API.
- Создание борды, профилей ролей (clone + `reasoning_effort=max`), лимитов канбана,
  cron-джобы стража, `.gitignore`.
- Маркер `.pipeline/VERSION` и `setup --upgrade`: обновление движка в проекте без
  переустановки плагина и без потери конфига.
- Инструменты агента: `pipeline_status`, `pipeline_run`, `pipeline_control`.
- Тесты: 48 плагина + 48 движка (e2e с поддельным `hermes`, фейковый Bot API, UI, предпросмотр).
