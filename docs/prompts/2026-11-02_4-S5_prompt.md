## 6. Как проверить (гейты)

Из корня репозитория (Windows, bash):

    .venv/Scripts/python.exe -m pytest tests/test_roles.py; echo EXIT=$?
    .venv/Scripts/python.exe -m pytest; echo EXIT=$?
    hermes plugins validate step_pipeline; echo EXIT=$?

Ожидается: `4 passed` (EXIT=0); полный прогон — без новых падений, базовая линия
замеряется до правки и оба числа идут в отчёт (по отчёту S4 было 200 passed — это
ожидание, не замер); `Validation passed` (EXIT=0). Известное предупреждение
security-скана про `dump_all_env` — пре-существующее (ревью 4-S4, строки 68–71),
провалом не считать. Результат читается по коду возврата самой команды, поэтому
`; echo EXIT=$?`, а не хвост пайпа.
