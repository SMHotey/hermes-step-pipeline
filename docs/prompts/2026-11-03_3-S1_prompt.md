## 1. Цель

Панель перестаёт дёргать движок по таймеру: снимок кэшируется, отдаётся с ETag,
а изменения приходят событием, а не опросом раз в 5 секунд.
Готово = при открытой панели число запусков движка за минуту не больше 20 (сейчас
около 36); после кнопки Тик панель обновляется сразу, без ожидания очередного опроса;
неизменённый снимок отдаётся с 304 и не тратит процесс.

## 3. Что сделать

1. snapshot.py: кэш снимка на 2–3 секунды с ключом инвалидности по mtime плана,
   каталога состояния и базы борды; при неизменных ключах движок не запускается.
   Кэш потокобезопасен (панель обслуживает запросы в потоках).
2. ui_server.py: GET /api/snapshot отдаёт ETag (хеш снимка) и 304 при совпадении
   If-None-Match; формат JSON не меняется — инструменты и внешние вызовы не ломаются.
3. Новый поток событий GET /api/events (Server-Sent Events): при изменении ключей
   отправлять снимок клиенту; соединение не держать вечно — таймаут и повторное
   подключение на стороне клиента.
4. ui/index.html: подписаться на /api/events, обновляться по событию; опрос оставить
   резервным (интервал увеличить до 30 с) на случай, если события недоступны.
