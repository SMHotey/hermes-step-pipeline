# Промт: план 3 «Панель» / шаг S3 — экран «Шаг»: контракт, постановка, вердикт, коммит

План: docs/plans/3-panel.md, §S3. Шаг: S3 (1.5 дн). Дата: 2026-11-03.
Репозиторий: <корень>, ветка main.
Исполнитель: профиль pipeline. Всё по-русски.

## 1. Цель

Чтобы понять шаг, не нужно открывать четыре файла: контракт из плана, постановка,
отчёт ревью и коммит шага — на одном экране.
Готово = на экране шага видны: цель, файлы, гейты и критерий «Готово» из плана; текст
постановки (только чтение); отчёт ревью с подсветкой вердикта и находок; `git show`
коммита шага в обрезанном виде. Файл вне корня проекта не читается — это закреплено
тестом. Большой вывод обрезается с явной пометкой, а не молча.

## 2. Факты (проверено на дереве 03.11.2026)

- step_pipeline/ui/index.html — панель без сборки; данные берёт из /api/snapshot, события
  из /api/events (SSE), действия — POST /api/action.
- step_pipeline/ui_server.py — маршруты: /api/snapshot, /api/events, /api/action,
  /api/plan-mode, /api/health; сервер на 127.0.0.1, без авторизации.
- step_pipeline/snapshot.py — планы, шаги, карточки, журнал, решение стража.
- tests/test_ui_server.py — 24 теста (в плане написано 15: цифра устарела, план не правим,
  тесты не удаляем; цель — 24 + новые).
## 3. Что сделать

1. Новый маршрут `GET /api/step?plan=<N>&id=<S>`: контракт шага из плана (цель, файлы,
   гейты, «Готово =»), путь и текст постановки, путь и текст отчёта ревью, `git show
   --stat` и первые ~200 строк диффа коммита шага (коммит берётся из вердикта отчёта).
2. Защита путей: любой файл запрашивается только внутри корня проекта; выход за корень —
   400 с понятным текстом. Симлинки и `..` тоже отклоняются. Это отдельный тест.
3. Экран «Шаг» во вкладке: четыре блока (контракт, постановка, отчёт ревью, коммит),
   вердикт и находки подсвечены; блоки сворачиваются.
4. Карточки шага и правок — с результатами и ссылкой на комментарии.
5. Кнопки hold/unhold рядом с шагом; при стоп-флаге они остаются доступны.
6. Обрезка: свыше лимита — «показаны первые N строк, всего M», без тихого усечения.

## 5. Стоп-сигналы

Доложить, если: для `git show` нужен доступ к git из панели, а песочница его не даёт;
контракт шага нельзя собрать из снимка без правки движка (это план 2, не этот шаг);
защита путей требует менять формат снимка.
## 6. Границы

Не трогать: `step_pipeline/engine/*`, `docs/plans/*`, `pipeline.json`. Панель только
читает состояние и вызывает уже существующие действия. Постановки и отчёты — только
показ, без редактирования из интерфейса.

## 7. Отчёт и ревью

Отчёт: diff --stat; ключевые диффы (маршрут /api/step, защита путей, экран, обрезка);
фактические числа гейтов; что не сделано и почему.
