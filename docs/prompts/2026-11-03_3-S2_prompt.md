## 1. Цель

Владелец видит последствие кнопки до нажатия: что именно сделает страж, почему и
сколько шаг уже висит в текущем состоянии.
Готово = на проекте с незакрытым шагом обзор пишет «Тик: заказ постановки S2» и
причину; при стоп-флаге кнопка Тик недоступна и объясняет почему; предпросмотр
по-прежнему без действий.

## 3. Что сделать

1. Крупный блок «следующее действие и причина»: взять decision.action и reason из
   снимка, показать человеческими словами; кнопка Тик подписана этим действием
   («Тик: заказ постановки S2»), при стоп-флаге — недоступна и объясняет причину.
2. Прогресс планов: полоса с числами закрыто/всего по каждому ведомому плану.
3. Строки состояния: сколько висит в текущем состоянии, кругов правок, постановка
   есть/нет, риск шага (если поле уже есть в снимке — показать, если нет — не выдумывать).
4. Бейдж критичных проблем из проверок S5, если проверок ещё нет — не рисовать пустышку.
5. Предпросмотр остаётся без действий: ни один элемент не должен менять состояние.
