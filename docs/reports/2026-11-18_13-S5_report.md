# Отчёт: план 13, шаг S5 — метрика кругов: причина, класс, стоимость

## 1. Сделано

**§4.1. Поле причины в истории.** `step_pipeline/engine/gate.py::remember_action` — в строку
истории пишется `cause` (`str(decision.get("cause") or "")`, ключ есть у всех действий),
в докстроке поле перечислено рядом с `stale` с причиной: по нему метрика отличает круг,
открытый блокирующей находкой, от круга другого класса, не разбирая `detail`.

**§4.2. Причина в двух решениях `create_fix`.**
`step_pipeline/engine/gate.py::_step_registry_decision` — `cause` = старший класс открытых
строк (`gate.round_cause_of` по `kind` из `open_step_findings(ctx)`);
`step_pipeline/engine/gate.py::_decide_base` — `cause` = старший класс из `classes`
(`report_finding_classes_at`). Старшинство задано один раз константой
`gate.FIX_CAUSE_ORDER = gate.STEP_FINDING_KINDS`; `create_prompt_fix` ключ не получает.

**§4.3. Счёт для ретро.** `gate.py::round_cause_counts(records, plan_id)` →
`{"total", "blocking", "significant", "style", "prompt", "unknown"}` (стоит рядом с
`_median`/`_plan_metrics`). `step_pipeline/engine/analyze.py::retro_text` — необязательный
параметр `rounds`; при `None` текст прежний до символа, при словаре после строки «Дата: …»
появляется `Кругов правок: …`. Ветка `if action == "write_retro":` в `gate.py::run_gate`
берёт записи из `gate.history_lines(p.cfg)` и передаёт `round_cause_counts(records, p.plan_id)`
в `retro_text` — история второй раз не разбирается.

**§4.4. Метрика.** `step_pipeline/stats.py` — правило R12 в докстроке модуля, константы
`ROUND_CAUSES`, `ROUND_CLOSING`, `CLOSE_STEP_ACTION`; `_round_records`, `_round_report`,
`step_rounds_report` (ключи `rounds`, `causes`, `median_min`, `open`, `steps`);
`cycle_metrics` получил `round_causes`, `round_minutes_median`, `rounds_open`,
`rounds_by_step`, `first_try_steps`, `first_try_base`, `first_try_share` (прежние
`by_plan`, `zero_close_steps`, `zero_close_share` не тронуты); `cycle_tiles` — подсказка
пятой плитки дописана хвостом `; круги по классу: …; медиана круга X мин; с первой попытки
S из B`; `render_cycle` — тот же хвост одной строкой без переводов строки; публичный
`stats.step_round_causes(root, cfg, plan_id, step_id)` (шаг без учёта регистра, локальный
список ошибок истории).

**§4.5. Панель.** `step_pipeline/snapshot.py::_overview` — ключ `rounds_cause`
(`stats.step_round_causes(root, cfg, plan_id, step)`; `fix_rounds` оставлен как был).
`step_pipeline/ui/index.html`: в разметке `<i id="ov-rounds-cause">` под `#ov-rounds`,
CSS `.ov-item i` (обычный шрифт, 11px, `var(--muted)`, `display: block`), сетка `.ov-grid`
по-прежнему четыре колонки; в скрипте `roundsCauseText`/`roundsCauseTitle` и их вызов в
`renderOverview` — текст `кругов по истории: N (…) · медиана X мин`, ноль кругов —
`кругов по истории: 0`, нет данных — пустая строка, `title` — разбивка словами с
«источник: history.jsonl».

**§4.6. Тесты.** `tests/test_stats.py` — общая фикстура §4.6 (`round_history`) и три новых

## 4. Решения по умолчанию

- **Р1. Строка — на «Обзоре», вторая под числом «кругов правок».** Цена иного (экран «Шаг»):
  перенос строки в другой экран, ~0.2 дня.
- **Р2. Поле `cause` пишется только у `create_fix`.** Цена иного: второй словарь классов и
  расхождение с реестром постановки, ~0.3 дня и отдельное решение.
- **Р3. «С первой попытки» — ноль кругов любой серии у закрытого шага.** Цена иного: число
  выросло бы за счёт шагов с переписанной постановкой, ~0.1 дня.
- **Р4. Старые круги — `неизвестно`, backfill по отчётам не делаем.** Цена иного: разбор
  ~40 отчётов ревью и риск приписать класс неверно.
- **Р5. Строка ретро — в шапке черновика, через необязательный параметр `retro_text`.** Цена
  иного (строка в «Что вышло»): правка шаблона ретро и отдельный тест.

## 6. Находки

1. **Г6: «9 из 39» против «9 из 40»** — история выросла на четыре строки (закрытие 13-S4).
   Правило под ожидание не подкручивалось, оба числа в таблице §3, ручной пересчёт совпал
   с метрикой.
2. **§4.2 тестами напрямую не закрыт.** §3 ограничивает набор тестовых файлов четырьмя, и
   файлов `test_step_findings.py` / `test_review_verdict_classes.py` в нём нет; добавлять
   туда тесты значило бы выйти за объём шага. Поле проверено косвенно: `remember_action`
   пишет `cause` из решения (тест §4.6 п.2), а счёт читает то же поле (тесты §4.3 и §4.4).
   Если ревьюер считает нужным прямой тест решений — это правка двух строк в чужом файле,
   решение владельца.
3. **Медианы нет — «медиана круга — мин».** Так буквально читается «медианы нет — `—`»
   из §4.4 (X = `—`). Если владелец хочет «медиана круга —», это правка одной строки
   в `stats._round_cause_hint`.
4. **`step_rounds_report().steps` отдаёт четыре ключа** (`plan`, `step`, `rounds`, `causes`,
   `median_min`), без `open`: число незакрытых кругов живёт в общем счёте `rounds_open`,
   чтобы в разбивке не было второго числа того же смысла.
5. **`cause` в строке истории есть у всех действий** (пустая строка, если причины нет) —
   так требует §4.1; `HISTORY_KEYS` расширен, старые читатели поля не знают и не ломаются.
