Постановка: `docs/prompts/2026-11-20_10-S2B_prompt.md`. Задачи 1–8, адрес-символ у каждой.

1. **`gate.py::effective_plan_verdict`** — вердикт держит строка, у которой статус `открыто`
   **и** держащий класс (`PROMPT_FINDING_STATUS.get(kind, "открыто")`): `замысел`,
   `двусмысленность`, `гейт-исполнение` держат, `стиль` и `формат-стража` — нет.
   `view["open"]` теперь перечисляет ровно блокирующие ID, а статусы строк в файле не
   пересчитываются. `gate.open_findings_lines` не менялся.
2. **`gate.py::plan_review_card_body`** — абзац о правиле блокирования в разделе «РЕЕСТР
   НАХОДОК» называет порог: `открыто` + держащий класс; `стиль` и `формат-стража` не держат
   даже при `открыто` и остаются строками реестра; «подробность» — пометка внутри `стиль`.
   Ключевые слова карточки («НЕ code review», «связность», «1.5», `plan-1.md`, `APPROVE`,
   «Конституция», путь реестра, шапка таблицы, «Блокирует вердикт только») на месте.
3. **`gate.py::register_questions` + `question_measure_argv` / `measure_question` /
   `question_measure` / `parse_question_blocks`** — вопрос с командой замера в обратных
   кавычках (белый список: `sha256sum`, `shasum`, `grep`, `git rev-parse`) страж исполняет
   сам: `_run(argv, cwd=repo, timeout=60)`, без shell (метасимволы оболочки = вопрос не
   измерим). Успех — код 0 и непустой вывод после `.strip()`; в `history.jsonl` строка
   `action: "measure"` с `detail` «замерил: «команда» → «вывод»», неудача — «замер не
   удался: … — код N / таймаут 60 с / пустой вывод / не запустилась». Отметка
   `question_measures` в снимке `ctx["state"]` (пара «шаг + текст вопроса»), у пути без
   сохранения вопроса отметку сохраняет сам замер.
4. **`gate.py::questions_enforce`** — ключ `questions.enforce` читается из `p.cfg.state`,
   умолчание `true`, не-`bool` → `true`. `true` — строка вопроса не заводится вовсе;
   `false` — вопрос заводится и держит шаг, замер идёт только строкой журнала.
   `config.py` не менялся.
5. **Скиллы** — `pipeline-reviewer/SKILL.md`: пункт «**Порог подробности**» сразу после
   «Вердикт обязан совпадать с классами» (вне ограды образца вердикта);
   `pipeline-prompter/SKILL.md`: абзац про измеримый вопрос после «Вопрос с ID
   останавливает шаг». Больше в скиллах ничего.
6. **`tests/engine/test_detail_threshold.py`** — десять случаев задачи 6, каждый утверждает
   значение (вердикт, `open`, число карточек, строки файла вопросов, записи истории, вызовы
   `gate._run`); тесты 5–8 и 10 подменяют `gate._run`, ни один не зависит от бинаря на PATH.
7. **Golden не перезаписывался** — `tests/engine/golden/` не тронут, `GOLDEN_UPDATE` не
