## Находки

1. **[значимая]** `step_pipeline/setup_flow.py:531-536` — строка-комментарий внутри
   блок-списка обрывает разбор: `_parse_trusted_dirs` пропускает только пустые строки, на
   `# ...` item-регексп не матчится и срабатывает `break`. Проба:
   `skills:\n  trusted_project_dirs:\n    # мои проекты\n    - C:\a\n` → `[]`; комментарий
   между элементами отрезает все последующие пути. Следствие: `doctor` печатает ложную
   проблему «проект не доверен этому профилю» и команду починки; команда безвредна —
   `hermes skills trust` с уже доверенным путём печатает `Already trusted` и конфиг не
   пишет. Ожидание: пропускать строки-комментарии
   (`if follow.lstrip().startswith("#"): continue`). Не блокирует: постановка D3 прямо
   допускает «разбор не удался → пустой список», а в живых конфигах трёх профилей
   комментариев внутри списка нет (ключ один на файл).
2. **[значимая]** `tests/test_setup_flow.py:23-28, 207-216` — пропуск доверия по
   `--no-trust` не покрыт тестом: `args()` кладёт `no_trust=True`, `fake_hermes`
   возвращает код 0 на любой вызов, и ни один из 13 тестов не проверяет ОТСУТСТВИЕ
   вызовов trust. Если убрать ветку `setup_flow.py:776-777`, все 13 тестов останутся
   зелёными. Ожидание: пятый тест — setup с `no_trust=True` → ноль вызовов с `trust` и
   предупреждение «доверие проекту не оформлялось (--no-trust)». Не блокирует: поведение
   реализовано и проверено чтением кода, а контракт шага перечисляет ровно четыре теста.
3. **[стилистическая]** `step_pipeline/setup_flow.py:521` — разбор не привязан к родителю
   `skills:`: ключ `trusted_project_dirs`, вложенный в другую секцию, читается как
   доверие. Проба: `mcp_servers:\n  srv:\n    trusted_project_dirs:\n      - C:\zzz\n` →
   `['C:\zzz']`. В живых конфигах ключ встречается ровно один раз на файл, риска сейчас
   нет; ожидание при желании — сверять отступ родителя `skills:`.
4. **[стилистическая]** карточка исполнителя — отчёт не по всем семи разделам §8
   постановки (нет адресов изменений, самостоятельных решений, «что не сделано»,
   отклонений). Факты, которые я мог проверить, с моими прогонами совпали; на вердикт не
