## Контракт «Готово =» (docs/plans/3-panel.md:77-79)

1. «с пустого проекта мастер доводит до работающего конвейера без терминала» — да, состав шагов
   этим коммитом не менялся; повторно подтверждено моей пробой на HEAD: пустой каталог → GET
   `enabled true`, `next project`, у всех шагов `done false`; POST `project` → `next board`,
   `pipeline.json` с бордой и ролями; шаги `board`, `profiles`, `cron` зелёные и закрывают свои
   факты; `telegram` с токеном → `.env` профиля и `notify.enabled true`; `checks` → `next null`.
   Живьём на настоящем `hermes` шаги борды/профилей/cron не гонял: постановка §3 запрещает
   создавать профили, борды и cron на машине — проверено подделкой `run_hermes`.
2. «секрет не попадает ни в ответ API, ни в лог панели (проверяется тестом)» — да, закрыто.
   `ui_server.py:606` срезает токен формы ровно тем `.strip()`, которым его исполняет
   `run_setup_step` (`setup_flow.py:1405-1406`); редакция применяется к строкам лога, `error` и
   `state.note` (`ui_server.py:613-616`), в том числе на пути исключения (:609-611). Моя проба:
   значения `TOKEN`, `TOKEN + "\n"`, `"  " + TOKEN + "\r\n  "`, `TOKEN + "  extra"` при
   `get_me`, бросающем `TelegramError("Unauthorized: " + token)` → во всех четырёх случаях HTTP
   400, токена нет ни в теле, ни в `state.tail()`, в `error` и логе стоит `***`. На дереве 56fb091
   тот же сценарий с `"\n"` возвращает токен в `error`, `log` и `state.log`.
3. «отказ на середине оставляет проект в понятном состоянии и объясняет, с какого шага
   продолжить» — да, и зацикливание из находки круга 1 убрано: для всех шагов, кроме «Проекта»,
   борда и имена ролей берутся из `pipeline.json` (`setup_flow.py:1442-1450`), по нему же
   считаются факты (`_board_fact` :1310-1313, `_profiles_fact` :1315-1318, `_cron_fact`
   :1332-1353). Моя проба: проект с `profiles.driver = "shop"`, шаг `profiles` с формой
   `{"driver": "shop2", "prompter": "p2", "reviewer": "r2"}` → `ok true`, доверены `shop`,
   `prompter`, `reviewer`, профили `shop2`/`p2`/`r2` не создавались, `next: telegram`. Отказ
   доверия одной роли по-прежнему красит не шаг, а факт: `next` остаётся на `profiles`
   (:1481-1486), и владелец повторяет шаг — это и есть «понятное состояние». Текст отказа —
   последнее предупреждение лога (:1385-1390).
