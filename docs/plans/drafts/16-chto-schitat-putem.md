## Разведка

путь в теле шага; кандидатов 6 — собственный код репозитория, его документация и stdlib).

Решение: go — критерий «путь» один на два разных вопроса, и это причина шума. Сборщик шага
(`next_step::_looks_like_path`) оставляем: он наполняет поле `files` шага для карточки, где широкий
предикат уместен. У анализатора появляется свой строгий предикат для A2/A5.

Правки по разведке: 0

Лицензии кандидатов: MIT (собственный код репозитория), PSF (stdlib).

Вывод разведки: из 243 находок A2/A5 по всем планам к настоящим ссылкам на файлы относятся не

## Допущения

1. поле `files` шага (то, что печатается в карточке) не меняется: правка касается только
   анализатора. Иначе поехали бы карточки у всех живых планов, а это не задача этого плана.
2. Строгий предикат не «глушит» A5, а сужает вход: настоящая ссылка на отсутствующий файл
   по-прежнему находка (отсутствующий файл рядом с существующим каталогом — по-прежнему A5), и это фиксируется тестом.
3. Список известных расширений берётся из одного места (`plan_lint`): второй список в
   репозитории означал бы, что «путь» у линтера и у анализатора — разные вещи.
4. Имя без каталога (analyze.py) не объявляется путём «в никуда»: файл ищется по дереву,
   найден — A2 (существует, но не объявлен), не найден — A5.
5. Глоб — шаблон, а не файл: существование одного файла для него не проверяется. Отдельного
   кода «глоб не нашёл файлов» в план не заводим: это новая проверка со своими правилами, а не
   исправление шума.
6. HTTP-адрес (/api/projects) — маршрут, а не путь в дереве; и правило не заглядывает в код
   панели, а узнаёт адрес по форме токена.
7. Путь к ещё не созданному файлу (<plans_dir>/drafts/) не даёт A5, если родительского
   каталога в дереве нет: файл появится по замыслу шага, а не «отсутствует».

## Шаги

### S1. Строгий предикат ссылки: глоб, ключ конфига и адрес — не путь (0.5 дн) `pipeline`

- Цель: A2/A5 срабатывают только на настоящие ссылки: глоб, ключ конфига и HTTP-адрес молчат;
  имя без каталога ищется по дереву; путь к ещё не созданному файлу проверяется по родителю.
- Замер основания: 243 находки A2/A5 по планам репозитория, из них 60 ключей конфига, 16
  адресов, 10 глобов, 103 имени без каталога; план 10 — 21 ложная находка.
- Файл: `step_pipeline/engine/analyze.py`, `tests/engine/test_analyze.py`.
- Что сделать:
  1. `analyze._ref_path(token, root) -> str | None` — строгий предикат ссылки: глоб
     (`*`, `?`, `[`) → `None`; HTTP-адрес (начинается с косой черты и не имеет известного расширения) → `None`;
     ключ конфига (нет косой черты, есть точка, последний сегмент не известное расширение)
     → `None`;
     иначе — путь.
  2. Набор расширений брать из `plan_lint` (одно место в репозитории), а не заводить второй.
  3. `_path_tokens` для A2/A5 вызывает `_ref_path`; имя без каталога разрешается поиском по
     дереву (`rglob`), а не проверкой в корне.
  4. `_exists` дополнить проверкой родителя: A5 не срабатывает, если родительского каталога в
     дереве нет (путь «к созданию»).
  5. Докстринг `_path_tokens` дополнить: он больше не совпадает с `next_step::_looks_like_path`
     буквально, а совпадает по назначению — «карточка шире, находка строже».
- Прогон: `python -m pytest tests/engine/test_analyze.py -m "not slow"` → exit 0, «passed»; таймаут 900
- Тесты/гейты: `python -m pytest tests/engine/test_analyze.py` → новые кейсы: ключ конфига
  watchdog.card_deadline_hours молчит; глоб step_pipeline/engine/*.py и */10 молчат;
  /api/projects молчит; имя без каталога (config.py) — A2, когда файл есть в дереве, и A5, когда нет;
  отсутствующий файл при существующем родительском каталоге — A5; <plans_dir>/drafts/ молчит.
- Риск: normal
- Готово = новые кейсы зелёные, `python -m pytest tests/engine/` зелёный, `ruff check .` чистый,
  `python .pipeline/analyze.py docs/plans/10-smotritel-sessiy.md` → содержит «ИТОГ: PASS».
- Важно: не менять `next_step::_looks_like_path`; не заглушать A5 целиком; не добавлять новых
  кодов проверки.
- Стоп, если: чтобы убрать шум, предлагают вывести «путь» из текста находки или из мнения
  модели — это нарушение п.5 конституции; либо правка требует изменения поля `files` шага.
