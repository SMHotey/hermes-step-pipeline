# 3. Панель: работа и настройка

Цель: панель становится тем, чем пользуются каждый день, — настройка проекта, разбор
шага, диагностика и управление без терминала и без ручного открытия файлов.

## Контекст

Сейчас ui/index.html — 370 строк без сборки: поток шага, планы, таблица шагов, карточки,
хвост таблицы закрытия, кнопки Тик/Стоп/Продолжить, настройки и Telegram. Работает, но
для ежедневного пульта не хватает четырёх вещей:

- Ответ на вопрос «что сделает Тик» надо выводить из строки решения, а не угадывать.
- Любая деталь шага (постановка, отчёт ревью, коммит, находки) — это открыть файл руками.
- Установка и диагностика остались в CLI: мастер setup, doctor и линтер плана в панели
  недоступны.
- Панель однопроектная, а обновление — опрос снимка каждые 5 с, то есть три запуска
  движка на итерацию (около 17 тысяч запусков Python в сутки при открытой вкладке).

Предпосылки из других планов: линтер плана и doctor --plan (план 1, S8), защита API от
чужой страницы (план 1, S7), история тиков и метрики (план 2, S3), риск шага и hold
(план 2, S1). Шаги S2, S3, S5, S9 без них не сделать; S1, S4, S6, S7, S8 — независимы.
S10 (уведомления) опирается на реестр проектов из S6 и на защиту API от чужой страницы
(план 1, S7).

Правила, которые панель не нарушает: только localhost, без авторизации, без сборки и
внешних зависимостей, в предпросмотре действия запрещены, секреты (токен бота) в браузер
не возвращаются ни в каком виде.

## Шаги

### S1. Снимок с кэшем и живое обновление (1 дн)

- Цель: панель перестаёт запускать движок по таймеру и обновляется по событию.
- Файл: `step_pipeline/ui_server.py`, `step_pipeline/snapshot.py`, `tests/test_ui_server.py`
- Тесты/гейты: `python -m pytest tests/test_ui_server.py -q` → 12 passed
- Что сделать: кэшировать снимок процесса на 2–3 с с инвалидацией по mtime плана,
  каталога состояния и базы борды; отдавать ETag и 304 на неизменённый снимок; добавить
  поток событий /api/events (EventSource), который пушит снимок при изменении; GET
  /api/snapshot оставить совместимым для инструментов и внешних вызовов.
- Готово = при открытой панели число запусков движка за минуту не больше 20 (сейчас
  около 36); после кнопки Тик панель обновляется без ожидания очередного опроса;
  неизменённый снимок отдаётся с 304 и не тратит процесс.
